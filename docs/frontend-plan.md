# Фронтенд: что сделано и что дальше

Рабочий документ, чтобы договорённости не терялись между сессиями.
Не часть ВКР, просто заметки по интерфейсу.

## Что уже есть

- Каркас: боковое меню с иконками, верхняя панель с поиском, контент.
- Палитра «бумага и чернила» на CSS-переменных (`:root` в `style.css`):
  без градиентов, малые скругления, антиква в заголовках, линейки вместо теней.
- 8 экранов: обзор, документы, документ, проверка, загрузка, поиск, вопрос, вход/регистрация.
- Компоненты: карточка документа, бейдж статуса, поле, оповещение, пустое состояние,
  чипы фильтров, пагинация, зона загрузки.
- Иконки — инлайновый SVG-спрайт в `base.html`, без внешних зависимостей.
- JS (`app.js`, ~120 строк): drag-and-drop, автовысота полей, авто-применение
  фильтров, подтверждение удаления, подпись «обрабатываю» на кнопке,
  опрос статуса обработки.
- Фоновая обработка: загрузка отвечает сразу, статус обновляется сам.

## Приоритеты

### P0 — нужно к защите

1. **Экран «Качество»** из `eval/results/*/summary.json` (4 ч).
   F1 по полям, матрица ошибок классификации, топ ошибок из `errors.csv`,
   дата и конфиг прогона. Цифры в работающей системе убеждают сильнее презентации.
2. **Провенанс на странице документа** (2–3 ч).
   Блок «как это получено»: модель, версия промпта, тип задан вручную или
   классификатором, время обработки, токены, число исправленных полей.
   Данные уже лежат в `processing_meta`.
3. **Чистый запуск по README** и записанный сценарий демонстрации (2–3 ч).

### P1 — заметно улучшает демо

4. **«Совпавшие поля» в результатах поиска** (3 ч): по какому полю сработал фильтр.
5. **История Q&A** в рамках визита (3 ч): список вопрос-ответ, повтор вопроса.
6. **Партиалы** (2 ч): `_doc_card.html`, `_pager.html`, `_empty.html` —
   сейчас карточка документа повторена в трёх шаблонах.

### P2 — удобство, не влияет на оценку

7. Сортировка списка: дата, название, статус.
8. Кнопка «Повторить» прямо в карточке упавшего документа.
9. «Скачать JSON» и `@media print` для страницы документа.
10. Кнопка «Взять пример» на загрузке — файл из `eval/dataset`.
11. Страницы 404 и 500 (сейчас при `DEBUG=False` покажется голый Django).
12. `title`-подсказки на обрезанных названиях.

## Доступность

- Достарх: `--faint` (#9a948a) на бумаге (#f6f4ef) даёт контраст **2,76:1**
  при норме 4,5:1. Использовать его только для декора, а подписи перевести
  на `--muted` (#6f6a61) — там 4,92:1.
- Иконочным кнопкам нужны `aria-label`; у SVG-спрайта уже стоит `aria-hidden`.

## Чего не делать

- SPA, React, сборка, TypeScript — для 8 экранов это потери.
- UI-киты (Bootstrap/Tailwind) — обнулят текущий вид.
- HTMX — опрос статуса уже закрыт 30 строками своего кода.
- Тёмная тема — пока не готов основной сценарий.
- Графики и дашборды — кроме F1 показывать нечего.
- Массовые действия, ZIP, drag-and-drop сортировка — это «после ядра» по ТЗ.

## Правила, чтобы вёрстка не расползлась

1. Новый вид — новый модификатор класса (`btn--ghost`), а не `style="..."`.
2. Логика остаётся на сервере: шаблон ничего не решает, JS только показывает.
3. Повторяющийся блок — сразу партиал, а не копия.
4. Один источник цветов — `:root`; литералов цветов в правилах не заводить.
